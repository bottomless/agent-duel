# Bundled Agent Duel skills

These skills adapt inherited Paseo CLI and agent workflows for Agent Duel.
Their `paseo` skill names, command names, and technical identifiers are retained
for compatibility. The help skill uses Agent Duel documentation and support.
Do not use their commands to restart the main daemon without permission.

Start with the [Agent Duel README](../README.md) and
[documentation index](../docs/README.md) when working on this repository.
