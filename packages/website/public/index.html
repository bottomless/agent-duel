Agent Duel

Code. Vote. Advance AI.

Put two coding agents to the test on your own projects. Compare their work, choose the better result, and keep building.

Remote connection

One prompt. Two perspectives.

  1. Start with your project

    Download Agent Duel for macOS, open a Git repository, and describe what you want to build.

  2. Compare the work

    Two coding agents tackle the same prompt in separate worktrees. Their model names stay hidden while you review the results.

  3. Choose and keep building

    Vote for A, B, or a tie. The models are revealed, and you continue from the selected result.
