# Getting help

- **Questions:** open a blank issue. Search existing issues first.
- **Bugs:** use the Bug report form. Include the version, how you run Agent Duel, and logs.
- **Feature ideas:** use the Feature request form.
- **Security vulnerabilities:** report them privately as described in [SECURITY.md](SECURITY.md).
- **Setting up a source build:** see [CONTRIBUTING.md](CONTRIBUTING.md#development-setup).

Agent Duel is maintained by a small team; replies can take a few days.
